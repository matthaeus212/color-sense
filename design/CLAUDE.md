## 지켜야 할 것

- 배경색 중심 화면 유지, 광고 영역 없음 (1차 비공개·비상업 전제)
- 계절 틴트 없음 — 온도 대역 + 날씨 구성 + 주야로만 표현
- 데이터 상태(지연·대체·오프라인·기본도시)는 배지로만, 배경색은 절대 바꾸지 않는다
- 동적 배경 위 텍스트 대비 규칙(WCAG AA 지향), 한글/영문 타이포는 각각 서체·자간·웨이트를 정해서 스펙화
- 출처 표기는 설정 하단 + 상세 시트 최하단 소형 텍스트로만, 홈 화면엔 넣지 않는다

### 대비 규칙
- 흰 텍스트가 놓이는 영역은 상단 52%(스톱 0~2)로 한정한다. 27° 이상 주간의 하단 스톱(#f0c896 계열)은 흰 텍스트 대비가 3:1 미만이므로 도시명·좌표 블록 뒤에 `linear-gradient(transparent, rgba(0,0,0,.18))` 스크림을 깐다.
- 12px 미만 텍스트의 최소 불투명도는 .75로 올린다(프로토 .55~.65 → 변경).
- 영하(−15~0°) 야간 팔레트는 전체가 매우 어두우므로 별·입자 효과의 밝기를 1.2배로 보정한다.

## 3. 데이터 상태 4종 + 보조 배지 시각 언어 (D4: 배경색 불변)

| 상태 | 표기(한/영) | 스타일 | 위치 |
|---|---|---|---|
| fresh | 없음 | — | — |
| stale | 갱신 지연 / UPDATE PENDING | 반투명 검정 필, 흰 테두리 .35 | 좌상단 시계 위 배지 행 |
| delayed | 오래된 데이터 / OUTDATED | 적갈색 필(rgba 120,40,40,.45) | 동일 |
| offline | 오프라인 / OFFLINE | 적갈색 필 | 동일 |
| fallback | 대체 데이터 / FALLBACK DATA | 반투명 검정 필 | 동일, stale 뒤 |
| defaultCity | 기본 도시 / DEFAULT CITY | 반투명 검정 필 | 동일 |

배지는 9px 대문자 자간 2px, 높이 22px, 최대 2줄 래핑. 배경색과 대기 효과는 상태에 따라 변하지 않는다. 상세 시트 최하단 `attrib` 줄에 `갱신 HH:MM · 예측 · 데이터 출처: 기상청 · 에어코리아 · 천문연 · Open-Meteo(링크)`를 9.5px .55로 둔다(D7).

## 4. 상세 시트 와이어 (스와이프 업, 높이 78%)

```
┌──────────────── 핸들 ────────────────┐
│ 상세 정보                            │
│ ┌ 바람 ┐ ┌ 습도 ┐ ┌ 강수확률 ┐ ┌ 파도 ┐ │  2×2 타일 (파도는 2차 전까지 "—")
│ 시간별 (가로 스크롤 24칸)             │
│  05  06  07  08 …                    │  시각 / 아이콘 / 온도 / 강수확률%
│ 주간 예보                            │
│  오늘  ☁  19° ━━━━━━━━  27°          │  7행, 온도 범위 막대(BOT 팔레트)
│  화    🌧 18° ━━━━━━    24°          │
│  …                                   │
│ 갱신 05:10 · 데이터 출처: 기상청 · … │  attrib
└──────────────────────────────────────┘
```

홈 화면 헤더에는 시간·날짜·구성 라벨·큰 온도 아래에 `체감 21°`(12px .8) 한 줄이 추가된다. 제스처: 시트 열기/닫기는 핸들·시트 헤더·홈 빈 영역에서만, 시간별 스트립과 주간 목록 안에서는 스와이프가 시트를 닫지 않는다.
